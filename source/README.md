# 株式会社Bridge 会社サイト

## 制作段階

1. フレームワーク構築：完了
2. デザイン制作：実装済み（ローカル確認用）
3. 6ページ化と本文整理：実装済み

提供された会社情報をもとに、ページの役割に合わせて本文を整理しています。自社SaaSなどの将来構想は、現在提供中のサービスと区別して記載しています。

## 構成

| URL         | 内容                                                   |
| ----------- | ------------------------------------------------------ |
| `/`         | トップ。企業紹介・事業・強みの概要、詳細ページへの入口 |
| `/business` | 5事業の支援内容、対応する課題、支援の進め方            |
| `/about`    | ミッション、ビジョン、6つの価値観、事業方針            |
| `/company`  | 確認済みの会社情報                                     |
| `/contact`  | 問い合わせ入力・内容確認。送信は未接続                 |
| `/privacy`  | プライバシーポリシー案                                 |

共通ヘッダー・フッター、スマートフォン用メニュー、各ページのタイトルと説明を実装しています。

提供された写真2点を `public/images/` に配置しています。トップは打ち合わせ、会社概要はワークスペースのイメージです。実在する社員・オフィスの写真としては扱いません。スマートフォンでは写真と本文を縦に配置します。

提供されたSVG3点は `public/decorations/` に配置し、接続ラインをトップ、円弧を価値観、区切り線をトップの事業紹介と強みの間に使用しています。原本は変更せず、CSSで配置を調整しています。

## 開発

Node.js 22.13以上とpnpmを使用します。

```sh
pnpm install --frozen-lockfile
pnpm run dev
pnpm run build
pnpm exec tsc --noEmit
```

共有版の起動・静的書き出し手順は、親フォルダのREADME-FIRST.mdを参照してください。

## 次工程への引き継ぎ

- `lib/company.ts`：提供情報に基づく会社概要、事業、価値観。
- `app/**/page.tsx`：各ページの本文と構成。
- `app/globals.css` / `app/pages.css`：共通デザインとレスポンシブ対応。
- `app/layout.tsx`：日本語設定、仮メタデータ。デザイン確認用として検索インデックスを無効にしています。正式公開時に再確認してください。
- 代表者名、詳細住所、設立日、問い合わせ先は未提供のため掲載していません。
- ロゴはテキストによる仮表記です。写真とSVGはユーザー提供素材に置き換え済みです。配置は `app/assets.css` で調整します。
- 問い合わせフォームは入力検証、確認、修正まで実装。実際の送信は無効です。入力データはReactのメモリ内だけで扱い、サーバー送信、ブラウザー保存、ログ出力を行いません。JavaScript有効化前は入力欄を無効化しています。
- 受付メールアドレス、送信サービスと必要な認証情報、実際の個人情報取り扱いを確定した後に送信機能を接続します。
- プライバシーポリシーは案です。詳細住所・代表者・窓口、実際の安全管理措置、委託先、保管期間等を確認して確定します。参考：[個人情報保護委員会Q&A](https://www.ppc.go.jp/personalinfo/faq/APPI_QA/)。
- 公開・デプロイは未実施です。正式公開までは検索インデックスを無効にしています。
